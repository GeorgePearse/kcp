What was sent?

Actual H.264-encoded conveyor footage at1920×1080,10fps. Five independently encoded one-second segments repeat throughout each run. Target rates:0.25,0.5,1,2,4,5.5Mbit/s; x264 CBR/filler, veryfast, no B frames. Every received segment must match its source SHA-256; each source segment was decoded to ten frames. Lower bitrates can reduce visual quality; this benchmark does not evaluate detector accuracy or perceptual quality.

Scope

TCP CUBIC, KCP with built-in congestion control and windows128, and plain UDP with fragment metadata/no recovery. Real processes in isolated Linux network namespaces;5Mbit/s each direction. Fixed pre-encoded payloads, no capture/encode timing. No GStreamer/RTP/RTSP, FEC, QUIC, TLS, production GCS, cross-traffic or GPU hardware. Requiring every fragment of a one-second segment is conservative for UDP compared with players that conceal damage. Extra stall time is a deterministic virtual-player result; missing segments give a lower bound.
